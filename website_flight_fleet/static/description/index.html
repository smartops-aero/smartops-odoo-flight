Why Website Fleet Display Matters?

In the charter aviation business, your fleet is your product. Potential clients need to see detailed aircraft information, amenities, seating configurations, and specifications before making booking decisions. A professional online fleet showcase is essential for lead generation and client conversion.

Website Flight Fleet seamlessly integrates your SmartOps aircraft database with your public-facing Odoo website, automatically publishing fleet details with beautiful, responsive layouts that work on any device.

Display Formats

Getting Started

Installation

  1. Install SmartOps Flight base module
  2. Optionally install Flight Aircraft Spec for specifications display
  3. Install Website Flight Fleet from Odoo Apps menu
  4. Configure which aircraft to publish on your website

Quick Start Guide

1. Set Fleet Visibility: Mark aircraft as published on your aircraft records

2. Add Photos: Upload high-quality aircraft images to your aircraft records

3. Create Fleet Page: Use Odoo Website builder to create a fleet page

4. Add Snippets: Drag fleet display snippets onto your pages

Customization Options

All snippets support Odoo's website builder customization options. Adjust colors, spacing, fonts, and layouts to match your brand without coding.
