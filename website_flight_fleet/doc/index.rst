======================
Website Flight Fleet
======================

This module provides website integration for displaying aircraft fleet information online.

Features
========

- Publish aircraft details on your website
- Display fleet information in various formats (accordion, carousel)
- Showcase aircraft amenities and specifications
- Integrate with flight_aircraft_specifications and flight_aircraft_amenities modules

Installation
============

Install this module by:

1. Copying this module to your Odoo addons directory
2. Installing the module from the Odoo Apps menu

Configuration
=============

After installation:

1. Go to Website → Configuration → Settings
2. Configure the fleet display options
3. Customize the website snippets for fleet display

Usage
=====

To use this module:

1. Go to Website → Pages
2. Create or edit a page
3. Use the provided snippets to display fleet information:

   - Fleet Accordion
   - Fleet Carousel
   - Multiple Fleet Carousel
