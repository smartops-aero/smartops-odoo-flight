Web Timezone Switcher

Real-time timezone switching for Odoo display without database modifications. Switch between timezones instantly — all datetime fields update automatically.

Session-Based No DB Changes Auto Re-render Persistent

What Is It?

This module adds a systray dropdown that allows users to switch their display timezone in real-time without modifying any database records. All datetime fields automatically re-render in the selected timezone. Perfect for aviation operations, global teams, and multi-timezone business operations.

See It In Action

Systray dropdown with live clock, search, and one-click reset.

Key Features

Session-Based Switching

No database modifications. Timezone preference is stored in session context only, keeping your user records clean.

Auto Re-rendering

All datetime fields update immediately when you switch timezone. No manual refresh needed.

Persistent Preference

Your timezone choice survives page reloads via localStorage. Resets after logout for security.

Full IANA Support

Complete pytz timezone database with 400+ timezones. Search by city, country, or region.

Smart Search

Quick timezone lookup with search-as-you-type. Timezones organized by region for easy browsing.

Live Clock Display

Shows current time in selected timezone with live updates. Override indicator when using non-default timezone.

Use Cases

Aviation Operations

View flight times in departure, arrival, or UTC timezone. Perfect for dispatchers and operations teams working across time zones.

Global Support Teams

Switch to customer's timezone to understand when issues occurred. Better communication and faster resolution.

Multi-Region Business

View reports in regional timezones: APAC, EMEA, Americas. Make sense of data in local context.

How It Works

  1. Click the timezone dropdown in the systray (top-right corner)
  2. Search or browse available timezones by region
  3. Select a timezone — all datetime fields re-render immediately
  4. Reset to default — click "Reset to Default" when in override mode

Technical Highlights

No Database Modifications

All times in the database remain in UTC. Only the display is affected. User records are never modified.
