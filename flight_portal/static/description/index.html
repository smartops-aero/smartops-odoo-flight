Flight Portal

Portal access for sharing flight information with external users via secure access tokens

Secure Tokens Portal Views Access Control External Sharing

What It Does

Flight Portal adds powerful portal functionality to the Flight module, enabling secure sharing of flight information with external stakeholders through Odoo's standard portal framework.

Share flight details with clients, partners, or crew members without granting full system access. Portal users can view flight information through secure, unique URLs with fine-grained access control.

Core Features

Secure Access Tokens

Generate unique, secure URLs for sharing flight information. Token-based access ensures only authorized users can view shared flights.

Dedicated Portal Views

Custom portal views optimized for external users. Clean, focused interface showing only relevant flight information.

Fine-Grained Access Control

Security rules ensure portal users only access their authorized flights. Separate access rights for portal users.

Easy External Sharing

Share flights with clients, partners, or crew without system access. Portal users view details through their personal portal.

Quick Setup

  1. Install the module from Odoo Apps (requires flight, portal, and web modules)
  2. Go to Settings → Users & Companies → Users to create portal users
  3. Assign portal access rights to users
  4. Open a Flight record and use portal sharing features
  5. Share the generated secure URL with external users
