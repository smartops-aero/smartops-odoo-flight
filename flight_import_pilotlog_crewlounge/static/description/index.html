Flight Import PilotLog CrewLounge Module

This module is part of the smartops.aero project developed by Apexive.

The Flight Import PilotLog CrewLounge module extends the Flight Import PilotLog functionality with specific features for importing pilot logbook data from CrewLounge. This specialized module provides pre-configured mappings and transformations tailored for CrewLounge export formats, simplifying the import process for users of this platform.

Key Features

  • Pre-configured field mappings for CrewLounge export formats
  • Specialized data transformations for CrewLounge-specific data formats
  • Streamlined workflow for CrewLounge data imports
  • Built-in validation rules specific to CrewLounge data structures
  • Ready-to-use import templates for common CrewLounge export scenarios

Module Components

CrewLounge Transformers

Specialized transformation handlers that convert CrewLounge data formats to Odoo-compatible formats:

  • Date and time format conversion
  • Flight duration calculations
  • Aircraft type mapping
  • Airport code resolution

Default Mappings

Pre-defined mappings for CrewLounge exports include:

  • Standard CSV format mappings
  • Field name translations
  • Default value assignments

Import Templates

Ready-to-use templates for different CrewLounge export scenarios:

  • Basic flight log template
  • Detailed flight log with additional fields
  • Historical data import template
Note: This module requires the base Flight Import PilotLog module to be installed. Please ensure that module is properly configured before using the CrewLounge import functionality.

Integration and Usage

Using the CrewLounge import functionality is simple:

  1. Navigate to the Flight Import section in your Odoo instance
  2. Select the CSV file exported from CrewLounge
  3. Choose the appropriate CrewLounge template from the dropdown
  4. Assign pilots using the enhanced pilot selection dropdown
  5. Preview and validate the data
  6. Complete the import process

This module integrates seamlessly with the Flight PilotLog module to store and manage the imported data.
