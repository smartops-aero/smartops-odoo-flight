Aircraft Amenities

Enhance your flight management system with comprehensive aircraft amenities tracking. This module seamlessly integrates with the main flight module to provide detailed management of aircraft comfort features and amenities.

Key Features

  • Define and manage various aircraft amenities
  • Track amenity availability across different aircraft
  • Maintain detailed inventory of comfort features
  • Easy integration with the main flight module
  • User-friendly interface for amenity management

Benefits

  • Improved passenger comfort tracking
  • Better fleet management capabilities
  • Enhanced service quality monitoring
  • Streamlined amenity inventory management

Technical Details

  • Compatible with Odoo 16.0
  • Easy installation and configuration
  • Regular updates and support
  • Open source - LGPL-3 licensed
