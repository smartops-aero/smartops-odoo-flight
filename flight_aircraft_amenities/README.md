# Aircraft Amenities

This module extends the Flight application to manage aircraft amenities and comfort features.

## Features

- Define and manage various aircraft amenities and comfort features
- Track amenity availability across different aircraft
- Maintain detailed inventory of comfort features
- Integrate with the main flight module for comprehensive aircraft management

## Installation

Install this module by:

1. Copying this module to your Odoo addons directory
2. Installing the module from the Odoo Apps menu

## Configuration

After installation:

1. Go to Flight > Configuration > Amenities
2. Configure the available amenities for your aircraft

## Usage

To use this module:

1. Navigate to Flight > Aircraft
2. Select an aircraft
3. Go to the Amenities tab to manage the aircraft's comfort features
