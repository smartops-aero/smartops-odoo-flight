Flight UOM

Aviation-specific units of measurement for flight operations with accurate conversion factors

Nautical Miles Knots ICAO Standards Auto Conversion

What It Does

Flight UOM adds essential aviation units of measurement to Odoo's UOM system. This module provides standard aviation distance and speed units with accurate conversion factors that follow international aviation standards.

Use nautical miles, statute miles, knots, and other aviation-specific units throughout Odoo. All conversion factors comply with ICAO and FAA standards for accurate flight planning and operations.

Available Units

Distance Units

  • Nautical Miles (nm) - Standard aviation distance
  • Statute Miles (mi) - Alternative distance measurement
  • Kilometers (km) - Metric distance measurement

Speed Units

  • Knots (kt) - Standard aviation speed
  • Kilometers per hour (kph) - Metric speed
  • Feet per second (fps) - Vertical speed

Conversion Factors

All conversion factors follow international aviation standards for accurate calculations:

1 nautical mile = 1.852 kilometers
Standard aviation distance conversion
1 statute mile = 1.609344 kilometers
Standard land mile conversion
1 knot = 1 nautical mile per hour
Standard aviation speed unit

How to Use

Installation

Using Aviation Units
  • Units are available in any UOM field throughout Odoo
  • Select from the Distance or Speed categories
