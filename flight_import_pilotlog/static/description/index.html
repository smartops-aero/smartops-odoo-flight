Flight Import PilotLog Module

This module is part of the smartops.aero project developed by Apexive.

The Flight Import PilotLog module extends Odoo's import functionality to provide specialized tools for importing flight logs from various pilot logbook formats into the flight management system.

Key Features

  • ✈️ Import flight data from various pilot logbook formats
  • ✈️ Customizable data transformers for different log formats
  • ✈️ Pilot selection for assigning default pilots to imported flights
  • ✈️ Preview transformation results before import
  • ✈️ Seamless integration with Odoo's import system

Module Components

Data Transformers

The module provides a framework for creating data transformers that can convert various flight log formats:

  • Define mapping between external data sources and flight models
  • Apply transformations to normalize data during import
  • Preview transformation results before final import

Import Interface

Enhanced import interface with flight-specific options:

  • Select a default pilot for imported flights
  • Choose appropriate data transformer for your log format
  • Visual indicators for transformation status
Note: This module requires the base flight module to be installed.

Integration and Extensibility

This module is designed to be extended with format-specific importers:

  • flight_import_pilotlog_crewlounge: For importing CrewLounge PILOTLOG data
  • flight_import_pilotlog_logten: For importing LogTen Pro data
  • flight_import_pilotlog_foreflight: For importing ForeFlight data
