# Aircraft Specifications

This module extends the Flight application to manage aircraft specifications and technical details.

## Features

- Maintain comprehensive technical information about aircraft
- Track performance characteristics
- Manage operational specifications
- Integrate with the main flight module for complete aircraft management

## Installation

Install this module by:

1. Copying this module to your Odoo addons directory
2. Installing the module from the Odoo Apps menu

## Configuration

After installation:

1. Go to Flight > Configuration > Specifications
2. Configure the technical specifications for your aircraft

## Usage

To use this module:

1. Navigate to Flight > Aircraft
2. Select an aircraft
3. Go to the Specifications tab to manage technical details
